# ttalkkag
딸깍은 HTML 태그를 화면에서 골라 조립하고 결과 화면과 코드를 나란히 보여주는 HTML 학습 도구다. 서버 없이 브라우저에서만 동작한다.
## 왜 만드나
HTML을 처음 배우는 사람은 태그가 외워지지 않아 검색을 하게되며 이로인해 흐름이 끊기게되고 손으로 친 코드가 화면에서 어떻게 보이는지 바로 보기도 어렵다.
딸깍은 태그를 골라 속성을 채워서 화면에 끼워넣으면 그 자리에서 결과와 코드로 바로 보여줘 검색창 없이 한 화면에서 배우게 하는것이 목표이다.
## 누가 사용하나
HTML을 막 배우기 시작해서 태그와 속성을 다 못 외우는 학습자들.
## 기능
### 태그 선택과 속성 편집
태그 종류를 클릭하면 그 태그에 맞는 속성 입력 폼이 뜨며 속성을 직접 지정, 수정, 삭제가 가능하다.

| 구분 | 내용 | 예 |
| --- | --- | --- |
| 공용 속성 | 모든 태그에 붙음 | id, class|
| 태그별 속성 | 태그마다 핵심 속성만 지원 | img의 src |
| 사용자 지정 속성 | '+' 버튼으로 data-* 속성 추가 | data-name |
### 제작과 배치
속성을 채우고 제작을 누르면 만든 태그가 마우스 커서를 따라다니고 렌더링부 또는 코드부에 클릭하여 배치가 가능
### 실시간 코드 확인
- 렌더링부에 배치하면 코드부에 반영 반영, 반대도 가능하며 두 화면에 순서는 같음
- 코드부에는 들여쓰기와 문법 강조가 적용됨
- 코드부에 복사버튼으로 코드를 클립보드로 복사
### 화면 구성
| 페이지 | 파일 | 하는 일 | 현재 상태 |
| --- | --- | --- | --- |
| 소개 | index.html | 딸깍이 뭔지 소개, 상단 대시보드 및 새 프로젝트 버튼 | 내용 구성 미정 |
| 대시보드 | dashboard.html | 사용자 간단 정보와 저장된 프로젝트 목록, 작업 화면으로 이동 | 와이어프레임 있음 |
| 작업 화면 | workspace.html | 태그 조립을 하는 화면 | 와이어프레임 구현됨 |
## 기술과 개발 방식
| 항목 | 기술 스택 |
| --- | --- |
| 언어 | HTML, CSS, Vanilla JS |
| 태그 데이터 | JSON 저장 후 렌더링 |
| JSON에 담을 것 | 태그 이름, 설명, 기본 형식, 속성 정보 |
| 폴더 | 따로 제한 없음 |

## 범위
### MVP에 넣는 것 
- 학습자용 태그 10~15개, p,h,img같은 태그에 더해 form처럼 학습에 필요한 태그까지
- JSON 항목만 늘리고 엔진이 렌더링
- 공용 속성과 태그별 핵심 속성, 속성 지정/수정/삭제
- 제작, 배치, 렌더링부와 코드부 동기화, 코드 복사
- localStorage 저장
